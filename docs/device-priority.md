# 设备适配优先级与真机验收

## 当前主设备

- HUAWEI Pura X View（VOL-AL00，HarmonyOS 7 / API 26，设备类型 `phone`）
- 2026-09-15 实测主屏：1320 × 2232 px，像素比 3，约 440 × 744 vp
- 后续版本以阔直板手机为首要布局目标；旧 Pad 不再作为首要验收设备

## 布局规则

界面按**窗口宽度 vp**适配，不按机型字符串适配。窗口缩放、分屏或系统字体变化时仍应可用。

| 宽度 | 布局定位 | 重点 |
| --- | --- | --- |
| < 400 vp | 普通窄手机 | 单列内容，底部紧凑导航 |
| 400–599 vp | 阔直板手机 | 首页横向信息带、代理模式与搜索同排、工具双列入口 |
| ≥ 600 vp | 平板 / 自由窗口 | 内容限宽，避免行过长 |

高度仍分为 `<600`、`600–899`、`≥900 vp` 三档。宽度断点定义在 `entry/src/main/ets/common/breakpoint/BreakPointSystem.ets`；页面使用语义辅助函数判断阔直板档。

## 每次发版前的真机检查

1. Pura X View 主屏打开首页、代理、配置、工具及工具子页；确认没有文字截断、横向溢出、底部导航遮挡。
2. 切换深浅色、系统字体大小及横竖屏/分屏；确认断点变化后页面仍可操作。
3. 导入并启用配置，选择代理节点，测试连接/断开 VPN，并检查连接、日志和请求记录。
4. 使用 `hdc` 确认安装、启动成功；保留安装输出与运行日志。无可用订阅时，至少核验空状态、页面导航与设置。

## 新设备调试签名

调试 HAP 必须由 `com.clashh.app` 的签名资料签发，且 profile 的 `debug-info.device-ids` 包含当前设备 UDID。换设备后先在 DevEco Studio / 华为开发者账号中为该包名刷新调试签名，再重新构建并安装。不要借用其他包名的 profile，也不要修改已签名 profile 的内容绕过授权。
